
# NPHA - Machine Learning Project

## Project Overview
This project was developed as part of the Year 2 Semester 1 (Y2S1) university coursework. It focuses on applying Machine Learning techniques to analyse the National Population Health Assessment (NPHA) doctor visits dataset.

## Project Objectives
- Explore and understand the dataset.
- Perform data preprocessing and cleaning.
- Apply suitable Machine Learning techniques.
- Evaluate model performance.
- Identify useful patterns from the dataset.

## Dataset
The project uses the NPHA doctor visits dataset.

- Dataset file: `NPHA-doctor-visits.csv`
- Target variable: `Number of Doctors Visited`
- Dataset location: `dataset/`

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

1. Clone or download this repository.
2. Install the required Python libraries.
3. Open `NPHA.ipynb` using Jupyter Notebook or PyCharm.
4. Run the notebook cells in order.
